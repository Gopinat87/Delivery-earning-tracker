# 🚚 Delivery Earning Tracker

## 📌 Overview

The **Delivery Earning Tracker** is a web-based application built using **Flask** that helps delivery partners efficiently track their daily earnings, fuel expenses, and overall profit.

This system provides a simple and intuitive interface to monitor financial performance and make better earning decisions.

---

## ✨ Features

* 💰 Track Daily Earnings
* ⛽ Record Fuel Expenses
* 📊 Profit Calculation (Automatic)
* 📅 Date-wise Entry Management
* 📈 Simple Analytics Overview
* 🧾 Clean and User-Friendly Interface

---

## 🛠️ Tech Stack

* **Backend:** Flask (Python)
* **Frontend:** HTML, CSS
* **Database:** SQLite
* **Version Control:** Git & GitHub

## ⚙️ Installation & Setup Guide

Follow the steps below to run the project locally:

---

### 🔥 Step 1: Clone the Repository

```bash id="i2h7h9"
git clone https://github.com/your-username/Delivery-earning-tracker.git
cd Delivery-earning-tracker
```

---

### 🔥 Step 2: Create Virtual Environment

```bash id="rj3n6k"
python -m venv venv
```

Activate it:

👉 Windows:

```bash id="f2a8j1"
venv\Scripts\activate
```

👉 Mac/Linux:

```bash id="c8k2m0"
source venv/bin/activate
```

---

### 🔥 Step 3: Install Dependencies

```bash id="j9w3d2"
pip install -r requirements.txt
```

---

### 🔥 Step 4: Run the Application 🚀

```bash id="l0p4q8"
python app.py
```

---

### 🌐 Step 5: Open in Browser

```id="z9x7c3"
http://127.0.0.1:5000/
```
